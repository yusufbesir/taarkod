# TAARKOD logo dosyaları
- taarkod-ikon.svg: kare uygulama simgesi (kaynak). Koyu çam yeşili #14513D, krem çubuklar #F6F1E3, etiket sarısı #F4C430. Barkod çubuklarının üstünde anahtar deliği (şifreleme), altında sarı dikiş izi (dokuma etiket). Kaynak ayrıca masaustu/build/logo.svg.
- taarkod-logo-yatay.svg: simge + yazı (tanıtım için). Yazı tipi sistem yazı tipidir; baskıda yazıyı eğriye çevirin.
- Kullanım kuralı: simgenin etrafında en az simge yüksekliğinin %10'u boşluk; zemin açık/koyu fark etmez (simge kendi zeminini taşır); renkleri değiştirme, gerilme yok.
- 16-32 px'te sarı şerit ve en kalın çubuklar okunur kalır; ince çubuklar bulanıklaşabilir, bu beklenen durumdur.
